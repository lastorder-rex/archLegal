# 모듈별 상세 개발 정의서

## Auth · 회원 모듈
- **OAuth Provider**: Kakao (`provider: 'kakao'`)
- **초기화**: `createClientComponentClient` (client), `createServerComponentClient` (server), `createRouteHandlerClient` (route).
- **회원 데이터 저장**: `users` 테이블 (RLS on). 키 필드 `auth_id` 고정, `full_name`, `email`, `phone` upsert.
- **콜백 처리**: `/auth/callback`에서 코드 교환 및 사용자 동기화.
- **세션 흐름**: 로그인 성공 → 자동 회원가입 → 세션 쿠키 발급 → 루트/로그인 페이지에서 환영 메시지 렌더링.
- **로그아웃**: `supabase.auth.signOut()` 호출 후 `router.refresh()`로 UI 상태 갱신.

추가 업데이트 시 `agent.md`와 CHANGELOG를 함께 수정합니다.

## Consultation · 상담 신청 모듈
- **주요 컴포넌트**: `ConsultationForm` 이하 주소/건물/메시지 섹션을 모듈화하여 유지보수성 확보.
- **검증 로직**: `lib/validations/consultation.ts`에서 Zod 스키마로 이름/연락처/주소/메시지를 검사하고 SQL/XSS 방지 필터 제공.
- **첨부파일**: 업로드 상태에 따라 제출 페이로드에서 자동 필터링, 완료된 파일만 전송.
- **빌딩 정보 연동**: 주소 선택 시 `/api/building/title` 호출로 건축물 요약 정보 선탑재.
- **테스트**: `components/consultation/__tests__/ConsultationForm.test.tsx`에서 제출 흐름 및 유효성 케이스 검증.

## MyPage · 마이페이지 모듈
- **경로**: `/mypage`, 세션 만료 시 `/login?redirect=/mypage`로 이동.
- **프로필 관리**: 기본 정보 자동 채움 후 `/api/users/profile` PUT으로 저장. 폰/이메일 필터와 포맷팅 제공.
- **상담 내역 탭**: `MyPageContent`가 상담 리스트/상세 분기 렌더링, `/request/history` 페이지와 라우팅 연계.
- **상태 관리**: 탭, 선택된 상담, 성공/오류 메시지를 로컬 상태로 보관.

## Docs · 문서 관리
- **구조 문서**: `docs/folder-structure.md` 갱신으로 주요 디렉터리와 설정 파일 역할 명시.
- **작업 가이드**: 본 문서에서 모듈별 핵심 구현 요약, 이후 변경 시 동시 업데이트 권장.
