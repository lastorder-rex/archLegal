# 모듈별 상세 개발 정의서

## Auth · 회원 모듈
- **OAuth Provider**: Kakao (`provider: 'kakao'`)
- **초기화**: `createClientComponentClient` (client), `createServerComponentClient` (server), `createRouteHandlerClient` (route).
- **회원 데이터 저장**: `users` 테이블 (RLS on). 키 필드 `auth_id` 고정, `full_name`, `email`, `phone` upsert.
- **콜백 처리**: `/auth/callback`에서 코드 교환 및 사용자 동기화.
- **세션 흐름**: 로그인 성공 → 자동 회원가입 → 세션 쿠키 발급 → 루트/로그인 페이지에서 환영 메시지 렌더링.
- **로그아웃**: `supabase.auth.signOut()` 호출 후 `router.refresh()`로 UI 상태 갱신.

추가 업데이트 시 `AGENTS.md`(에이전트 가이드)와 `docs/folder-structure.md`(구조 문서)를 함께 확인합니다.

## Consultation · 상담 신청 모듈
- **주요 컴포넌트**: `ConsultationForm` 이하 주소/건물/메시지 섹션을 모듈화하여 유지보수성 확보.
- **검증 로직**: `lib/validations/consultation.ts`에서 Zod 스키마로 이름/연락처/주소/메시지를 검사하고 SQL/XSS 방지 필터 제공.
- **첨부파일**: 업로드 상태에 따라 제출 페이로드에서 자동 필터링, 완료된 파일만 전송.
- **빌딩 정보 연동**: 주소 선택 시 `/api/building/title` 호출로 건축물 요약 정보 선탑재.
- **테스트**: `components/consultation/__tests__/ConsultationForm.test.tsx`에서 제출 흐름 및 유효성 케이스 검증.

## Diagnosis · 1분 양성화 자가진단 모듈
- **페이지/컴포넌트**: `/check` 라우트는 `app/check/page.tsx`에서 제공하며, 실제 진단 UI는 `components/diagnosis/LegalizationCheckClient.tsx`가 담당.
- **진단 로직**: `lib/diagnosis/legalization.ts`에서 질문, 답변 분기, 결과 등급, 상담 전환 문구를 관리하고 `app/api/diagnosis/route.ts`에서 서버 계산 API 제공.
- **스타일**: `app/check/diagnosis.css`를 별도 로드하여 자가진단 페이지 전용 레이아웃과 인터랙션을 분리.
- **공유/SEO**: 카카오 공유 및 OG 메타는 자가진단 전용 이미지와 `/check` URL을 기준으로 구성. 기존 정적 주소는 `next.config.mjs`에서 `/check`로 리다이렉트.
- **검증 문서/테스트**: `docs/legalization-1min-diagnosis-spec.md`에 질문/답변/결과 기준을 정리하고 `lib/diagnosis/__tests__/legalization.test.ts`에서 핵심 분기 검증.

## Enforcement Fine · 이행강제금 계산기 모듈
- **페이지/컴포넌트**: `/calc` 라우트는 `app/calc/page.tsx`에서 제공하며, 계산기 UI와 결과/상담 전환은 `components/enforcement-fine/EnforcementFineCalculatorClient.tsx`가 담당. `/enforcement-fine`은 `/calc`로 리다이렉트.
- **접근 흐름**: 로그인 필수 계산기로 운영하며, 미로그인 사용자는 로그인 모달/카카오 OAuth 후 원래 계산기 경로로 복귀.
- **준비 API**: `app/api/enforcement-fine/prepare/route.ts`가 주소/건축물대장/VWorld 개별공시지가를 조회하고 구조지수, 용도지수, 위치지수, 경과연수별 잔가율 후보를 조합.
- **계산 API**: `app/api/enforcement-fine/calculate/route.ts`가 위반유형, 위반면적, 사용승인연도, 특수조건, 감경/가중 후보를 받아 예상 이행강제금과 산출근거를 반환하고 `enforcement_fine_estimates`에 저장.
- **옵션 API**: `violation-types`, `structure-options`, `use-options` API가 DB 기준자료를 조회해 화면 선택지를 제공.
- **계산 로직**: `lib/enforcement-fine/prepare.ts`는 외부 API 조회/매핑, `lib/enforcement-fine/calculate.ts`는 건축법 제80조 및 2026 시가표준액 기준 계산식을 담당.
- **DB 기준자료**: `supabase/migrations/033_create_enforcement_fine_tables.sql`부터 `044_seed_additional_reduction_special_conditions.sql`까지 기준시가, 구조/용도/위치지수, 위반유형, 감경/가중 조건, 계산결과 저장 테이블을 구성.
- **운영 설정**: VWorld 호출 안정성을 위해 Vercel Function 기본 리전은 `icn1`(Seoul)로 운영. 환경변수는 `VWORLD_API_KEY`, `JUSO_API_KEY`, `BLD_RGST_API_KEY`, `NEXT_PUBLIC_SITE_URL` 확인 필수.
- **공유/상담 연계**: 카카오 공유는 계산기 전용 이미지와 `/calc` URL을 사용하고, 계산 결과 상담 신청 시 `calc_consultation_prefill` 세션 스토리지로 랜딩 상담 모달에 요약 정보를 전달.
- **검증 문서**: 계산 기준과 실제 사례 검증은 `docs/enforcement-fine/spec.md`, `docs/enforcement-fine/README.md`, `docs/enforcement-fine/verification-cases.md` 및 하위 기준자료 문서에서 관리.

## MyPage · 마이페이지 모듈
- **경로**: `/mypage`, 세션 만료 시 `/login?redirect=/mypage`로 이동.
- **프로필 관리**: 기본 정보 자동 채움 후 `/api/users/profile` PUT으로 저장. 폰/이메일 필터와 포맷팅 제공.
- **상담 내역 탭**: `/mypage/consultations` 라우트가 `MyPageConsultationsSection`으로 리스트/상세를 분기 렌더링하고 `/request/history`와 연계.
- **상태 관리**: `MyPageShell`이 컨텍스트로 프로필/상담 데이터를 전달하며, 각 하위 라우트가 필요한 UI 상태만 로컬로 보관.
- **결제 내역 탭**: `/mypage/payments`에서 Toss 위젯을 즉시 렌더링하며 성공 시 `/api/payments/confirm`을 호출해 상태를 반영, `/mypage/payments/success|fail`은 결과 안내 전용.

## Qna3D · 위반건축물 3D/실사 진단맵 모듈
- **페이지**: `/qna3d`(3D)·`/qna3d-photo`(실사) — 각각 `app/qna3d*/route.ts`가 `kick/*.html` 단독 HTML 서빙(3D판은 프로덕션에서 `qna3d.min.html`, `npm run build:kick`으로 생성·gitignore). 두 페이지는 툴바 버튼으로 상호 링크.
- **3D판 씬**: Three.js 0.160(**셀프호스팅** `public/vendor/three-0.160.0/`, importmap) 프로시저럴 모델 — 벽돌/화강석 CanvasTexture, 녹색 우레탄 옥상, 생활 소품(실외기·가스배관), 디오라마 받침대. 위반 12개는 실물 재질(골판 컨테이너·샌드위치판넬·어닝 등)이며 `vGroups[id]`에 실물/강조 재질 세트로 등록.
- **3D판 인터랙션**: 위반부위 강조 토글(zone 색), **적법 모습 토글**(위반 12개 숨김), **돌하우스 내부 보기**(10 근생→주거·11 세대쪼개기 — 2·3층 본체 면분해 + 내부 세트, 선택 즉시 전면 벽 개방), 패널 CTA(전문가 무료 상담=상담 오버레이·이행강제금 계산=/calc).
- **실사판**: AI 미니어처 디오라마 이미지(`public/3d.webp`, Real-ESRGAN 4배 업스케일→3072px) + 2D 팬/줌 + 정규화 좌표 핀. **적법 모습 크로스페이드**(`3d-legal.webp`), **내부 실사 썸네일→라이트박스**(`interior-10/11.webp`). 에셋 프로브 방식: 파일이 없으면 해당 UI 자동 숨김.
- **이미지 파이프라인**: 원본 PNG 생성(프롬프트: `docs/qna3d-photoreal-miniature-prompt.md` ⑨적법·⑩내부) → Real-ESRGAN 4배 → 3072px 리샘플 → `cwebp -q 84`. OG 미리보기 `3d-og.jpg`.
- **데이터**: 위반 12유형·Q&A 16문은 두 HTML 안에 동일 출처로 인라인(JSON-LD FAQPage·ItemList + noscript 폴백으로 SEO 커버). 진단 위저드는 `/api/diagnosis`·`/api/juso/search`·`/api/building/*` 연동.

## SEO · 전역 검색/AI 노출 모듈
- **사이트맵**: `app/sitemap.ts` 코드 생성(정적 라우트 + 지역 25 + 가이드 20 자동). 새 공개 페이지는 여기에 등록.
- **구조화 데이터 정본**: `app/layout.tsx`의 Organization/WebSite JSON-LD(`#organization`·`#website` @id를 타 페이지가 참조).
- **AI 노출**: `public/llms.txt`(핵심 페이지·인용 가능 사실), `public/robots.txt`(AI 봇 명시 허용).
- **지역 프로그래매틱 SEO**: `app/region/[region]/page.tsx` — `violation_buildings` 실데이터 + 이행강제금 통계.
