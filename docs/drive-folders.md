# 결제 완료 시 구글 드라이브 폴더 생성 가이드

## 개요
- 트리거: '양성화 대행서비스' 결제 성공 시 비동기 작업으로 폴더 자동 생성
- 최상위 위치: `GOOGLE_ROOT_FOLDER_ID` 하위에 고객별(결제별) 폴더 생성
- 인증: 서비스 계정(JSON) 사용, 폴더 공유는 이미 완료됨

## 폴더명 규칙
- 형식: `이름(금액천단위)_주소`
  - 금액: 원 단위에서 천단위까지만 표기 (예: 5,000,000원 → `5,000`)
  - 주소: 상세주소 제외한 기본 주소 사용
  - 문자 정리: 드라이브 금지문자(`/`) 등은 안전 문자로 치환, 공백·한글·괄호 허용
- 중복 처리: 동일한 `이름 + 금액천단위 + 주소` 조합이 이미 존재하면 휴대폰 번호(숫자만)를 접미사로 추가
  - 예: `김상우(5,000)_서울시신내로 51`가 있으면 `김상우(5,000)_서울시신내로 51_01012346788`

## 하위 폴더(초기값)
- 기본 생성 목록(순서 포함):
  1. `1. 인감증명서`
  2. `2. 위임장`
  3. `3. 현장 실사`
- 확장성: DB 테이블(예: `drive_folder_templates`)에서 `name`, `display_order`, `is_active`로 관리하여 손쉽게 추가/비활성화 가능하도록 설계

## 멱등성/재시도
- 생성된 최상위 폴더의 `drive_folder_id`를 저장하고, 동일 이벤트 재시도 시 해당 ID 재사용
- 충돌 시(이미 삭제되었거나 권한 이슈) 백오프 재시도 및 에러 로깅

## 권한
- 현재 별도 공유/권한 변경 없음. 추후 워크스페이스 전환 시 `supportsAllDrives`/`driveId` 옵션 사용

- 선택: `DRIVE_DRY_RUN=true` 설정 시 실제 생성 대신 로그만 출력(개발용)

## 데이터 저장(제안)
- 결제별 폴더 생성 요구 + 상담 단위로도 추적 필요 조건을 만족하기 위해 다음 중 하나 선택:
  - 권장: 매핑 테이블 `consultation_drive_folders(consultation_id, payment_id, drive_folder_id, created_at)` 추가
  - 대안: `payments.drive_folder_id` 저장 + `consultations`에는 최근 폴더만 별도 필드로 저장
- 현재 합의: 상담 단위 저장이 필요 → 매핑 테이블 방식으로 구현 시 다건 관리가 명확하고 확장성 높음

## 구현 체크리스트(요약)
- 결제 성공 핸들러에서 비동기 작업 큐 트리거
- 폴더명 생성 유틸: 금액 천단위 포맷, 주소 정규화, 금지문자 치환, 휴대폰 접미사 처리
- 드라이브 API 래퍼: 상위/하위 폴더 생성, 공유 드라이브 옵션, 멱등성 처리
- DB 저장: 폴더 ID 및 메타데이터 기록(상담/결제 연계)
- 설정화: 하위 폴더 템플릿을 DB에서 조회하여 생성

- 결과 폴더명: `김상우(5,000)_서울시신내로 51`
- 동일명 존재 시: `김상우(5,000)_서울시신내로 51_01012346788`
- 하위: `1. 인감증명서`, `2. 위임장`, `3. 현장 실사`
