# 이행강제금 계산기 실제 사례 검증표

이 문서는 실제 부과 사례와 계산기 결과를 비교하기 위한 검증 기준표다. 공식 계산기 또는 지자체 실제 부과액과 비교할 때는 아래 입력값을 동일하게 맞춘 뒤 차이를 기록한다.

## 검증 원칙

- 실제 부과액과 비교할 때는 주소만으로 판단하지 않는다.
- 위반부분 구조, 위반부분 용도, 위반면적, 위반완료연도, 건물 신축연도, 개별공시지가, 증축 기초공사 여부, 대수선 허가/신고 여부를 같은 값으로 맞춘다.
- 감경·가중·특례는 실제 부과서에 반영된 항목이 확인될 때만 일치 비교 대상으로 본다.
- 지자체 조례 또는 담당 부서 판단이 들어간 항목은 차이 사유로 별도 기록한다.

## 필수 비교 입력값

| 항목 | 필요 이유 | 자동화 가능성 |
|---|---|---|
| 주소 | 건축물대장, PNU, 개별공시지가 조회 | 가능 |
| 동/호수 | 전유부 면적·층·용도 확인 | 일부 가능 |
| 위반유형 | 별표 15 요율 결정 | 사용자 입력 |
| 위반면적 | 산식 핵심 값 | 사용자 입력 또는 부과서 확인 |
| 위반완료연도 | 잔가율 기준 | 사용자 입력 또는 부과서 확인 |
| 건물 신축/사용승인연도 | 대수선 보정 잔가율 기준 | 가능 |
| 위반부분 구조 | 구조지수·내용연수 결정 | 사용자 입력 또는 상담 확인 |

| 개별공시지가 | 위치지수 결정 | 가능 |
| 증축 기초공사 여부 | 증축 산정비율 결정 | 사용자 입력 |
| 대수선 허가/신고 대상 | 대수선 산정비율 결정 | 사용자 입력 |
| 감경·가중·특례 | 예상범위 산정 | 일부 가능, 대부분 확인 필요 |

- 필수 입력값이 모두 확인된 사례에서 공식 계산기와의 차이가 5% 이내면 `일치`.
